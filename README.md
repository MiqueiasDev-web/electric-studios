# ⚡ Electric Studios | Art & Code

Esta é a página web institucional da **Electric Studios**, um hub criativo e tecnológico focado em unir o desenvolvimento de software de alta performance (**Code**) com design de interface de ponta (**Art**).

O projeto conta com uma interface moderna em *dark mode*, totalmente responsiva e integrada com links diretos para contato via WhatsApp e e-mail.

---

## 🚀 Tecnologias Utilizadas

* **Node.js (puro):** Utilizado para criar um servidor HTTP local (`node:http`) e gerenciar o roteamento nativo de arquivos.
* **Tailwind CSS:** Framework utilitário utilizado via CDN para estilização rápida, moderna e responsiva de forma unificada no HTML.
* **HTML5:** Estrutura semântica da aplicação.

---

## 🛠️ Como rodar o projeto localmente

Para clonar e rodar este servidor na sua máquina, siga os passos abaixo:

1. Garanta que você tem o **Node.js** instalado no seu computador.
2. Baixe os arquivos do repositório para uma pasta.
3. Abra o terminal/prompt de comando dentro da pasta do projeto.
4. Execute o comando para iniciar o servidor:
   ```bash
   node server.mjs
